# Constructor for the MRMhubExperiment object

Constructor for the MRMhubExperiment object

## Usage

``` r
MRMhubExperiment(title = "", analysis_type = NA_character_)
```

## Arguments

- title:

  Title of experiment

- analysis_type:

  Analysis type, one of "lipidomics", "metabolomics", "externalcalib",
  "others"

## Value

`MRMhubExperiment` object
