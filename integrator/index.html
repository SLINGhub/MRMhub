INTEGRATOR

Peak detection, picking, and integration for targeted MRM mass spectrometry

INTEGRATOR is the stand-alone peak-integration application of the MRMhub pipeline. It reads mzML files, finds and integrates MRM peaks, and exports long.csv / quant_raw.csv for downstream quantitation in the QUANT R package.

INTEGRATOR is the stand-alone peak-integration module of the MRMhub pipeline. It takes converted mzML files, detects and integrates MRM peaks across all your samples, lets you review and fine-tune the results interactively, and exports tables ready for quantitation.

It ships as a small, self-contained executable for macOS and Windows — nothing to install, no Python or R required. Keep one copy in each analysis project folder and the whole project stays re-runnable.

The workflow

Note

Just want post-processing in R? INTEGRATOR is not required to use the QUANT R package — QUANT imports directly from vendor outputs (MassHunter, Skyline) as well. See the QUANT documentation ↗.

Next step in the pipeline

Once INTEGRATOR produces long.csv, hand it off to the QUANT R package for ISTD normalisation, drift/batch correction, calibration, QC, and reporting:

import_data_mrmhub("path/to/long.csv", import_metadata = TRUE)
